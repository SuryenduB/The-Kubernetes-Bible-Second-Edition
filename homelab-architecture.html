K3s Homelab Architecture

11-node K3s cluster on bare-metal Ubuntu hosts • physical LAN 192.168.0.0/24 • Longhorn + NFS storage • Tailscale + Cloudflare exposure

Access paths

  • • LAN → Tailscale operator exposes annotated Services on the tailnet
  • • Internet → Cloudflare Quick Tunnels (no token, ephemeral URLs)
  • • Audiobookshelf gated by abs-gate.py (login + HMAC session cookie)
  • • Homepage ungated — dashboard holds no library data
  • • kubectl apply -k ./kubernetes-manifests deploys everything

Storage & backup

  • • Longhorn default class for Postgres/MariaDB/MSSQL state
  • • longhorn-r1 single-replica for rebuildable data; 20% disk reserve
  • • NFS nfs-nas on Synology .128 for media + Ollama models
  • • Static NFS PVs keep explicit claimRef — do not remove
  • • immich-db-backup: nightly pg_dump to NAS + restore check

Operational guardrails

  • • kubernetes7 neverPowerOff (broken switch); nuc/server-236/252 neverCordon
  • • SSH case-sensitive: suryendub vs SuryenduB on servers
  • • Shutdown must run detached: pwsh ... shutdown_homelab.ps1 -Force
  • • cloudflare/ manifests stay out of the top-level kustomization
  • • Plaintext secrets checked in on purpose — homelab scope
