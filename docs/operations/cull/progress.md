## Phase 2 monitor reconciliation

The `uptime-kuma-sync` CronJob only creates/updates monitors and never deletes
them, so earlier Phase 2 removals that edited the ConfigMap left orphaned live
heartbeat monitors. After Apprise, the live Uptime Kuma monitor list was
reconciled against the retained app set: the orphaned `languard` and
`homelab-monitor` monitors were deleted via the API (they belonged to apps
removed earlier in Phase 2). A fresh query confirms no removed Phase 2 app
(apprise, kuvasz, trove, lan-sheriff, languard, lantern, homelab-monitor,
omnisight, pooml, logchef) has a live monitor. 55 monitors remain — the 54
ConfigMap-managed checks plus the manually-added `etcd-nas-backup`. This was a
live-only action (no manifest change); it is recorded here for the audit trail.
