## 🔧 Methodology

- Gmail query `from:selfh.st`, paginated; kept subjects with `Self-Host Weekly`.
- `text/html` payload parsed per section (`<h2>` + `<li>`); tool/version link (`email.mail.selfh.st` tracking URL) captured per bullet, `text/plain` used as fallback.
- Tracking URLs resolved by following redirects (usually GitHub repo/release pages); `?ref=selfh.st` stripped. Unresolvable tools stay plain text.
- Bullets parsed as `Tool [vVersion] | Category: Description`.
- Dedupe key = lowercase tool; latest version/category/link from newest issue.
